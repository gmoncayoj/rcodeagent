## Current behavior and material decisions

Model usage requires eligible ChatGPT Plus or Pro under OpenAI's Sign in with ChatGPT quickstart. Free inference is not supported by rcodeagent. A real Free connection attempt failed; the precise generic HTTP 400 cause is unconfirmed. Connection diagnostics now identify the failing stage/status and safe provider metadata without exposing raw response bodies or credentials. See `docs/validation/free-account-connection.md`.

Native ChatGPT OAuth requires neither an API key nor Codex CLI. A Background Job runs loopback Shiny while the console stays usable; chat remains in Viewer. **Normal** provides code, revisions and discussion only in chat. **Auto** edits an explicitly selected R target and submits execution only on an explicit request. It never saves automatically or executes every edit. Read-only UTF-8 R/md/qmd/Rmd attachments have limits; local JSON histories omit tokens and grants. The UI defaults to English, preserves saved English/Spanish choices and supports local exports. Language selection affects only the interface, independently of conversation language.

Explicit recapture of an eligible selection/document/R script preserves an already enabled Auto grant, cancels the prior worker and renews its generation when the snapshot changes. A current explicit imperative submits execution without a second confirmation, including new code and package installation. The Spanish “Ejecuta” uses captured context; “Instala el paquete lavaan” submits the exact call without implicitly editing or loading the package. Console, snapshot, syntax, conflict, IPC and no-replay checks remain. The user explicitly retained exact preview and one-use confirmation for classified administrative operations other than package installation after automatic review rejected removal of the general control. Quotations, negations and conditional/future instructions do not authorize execution. This is not a sandbox or exhaustive classification of R effects.

Each execution authorization is one-use, bound to the current request, Viewer owner, exact code and full target snapshot. A mode/target change, another request or Viewer detach discards pending execution permission. It is never recovered or replayed. `R/execution.R` enforces this boundary and model workers have no IPC. Code runs with the user's R session permissions.

The user approved Normal/Auto and tested native submission from a Job: `rcodeagent_qa_execution <- "idle"` appeared in the main session. Acknowledgment means submitted, not successfully evaluated; Chat Stop and Close cannot withdraw code. Output and Environment are not automatically collected for the model.

Addins recovery reuses the Job. Revalidating ID/path/full contents preserves Auto and the prior captured selection range; changes/failures revoke it. The client confirms restoration before queries/writes. A pending request is cancelled without replay and its instruction returns as a draft. Close ends the assistant; new Jobs, new chats and history-resumed chats start with Auto OFF.

## Earlier security repairs and limits

The 2026-10-17 audit found a medium foreign-client Viewer recovery issue and functional OAuth/path gaps. Original sealed audit: `10fc4cf0-29d1-4a5d-8738-690c5e4e5b4b`; medium CWE-346 finding `csf_4ea6e74d3191358905562a27`. Preserve that original audit rather than modifying it as a new review. `R/viewer-auth.R` validates exact Host/Origin and a private per-Job capability before initialization or state claim. Foreign HTTPS with local-network permission, even with the correct capability, and local clients with missing/incorrect capabilities were rejected, preserving the checkpoint for the legitimate client. Never log the fragment or trace initial Shiny inputs. Native compatibility of this admission change remains a separate pending check.

`R/auth-state.R` validates tokens/expiry/scope, serializes refresh using filelock, recovers/rolls back encrypted replacements and retains identity without tokens. Disconnect attempts remote revocation then removes local tokens, reporting unconfirmed revocation. Auxiliary metadata failures cannot block revocation or terminal-error removal. Credential POSTs do not follow redirects. Tests used synthetic transport/credentials rather than a real account.

`R/edit-patches.R` derives exact server patches and historical numbered diffs with full resulting code. Confirmation binds only to the reviewed proposal and does not survive Viewer detach as permission. Patch preparation precedes the final ID/path/full-content comparison. Save As/manual changes block writes and revoke Auto. There is one native insertText on the captured document/range.
