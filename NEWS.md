# rcodeagent 0.1.0

- Coding assistant in the RStudio Viewer with native ChatGPT OAuth authentication.
- Account-specific model selection, streamed responses and configurable reasoning effort.
- Normal mode for explanations and code drafts; Auto mode for explicitly authorized edits to a selected R document or selection.
- User-requested code submission to the RStudio console, with conflict checks and additional confirmation for sensitive administrative operations.
- Read-only context attachments, cancellable requests and recovery after temporarily leaving the Viewer.
- English and Spanish interface, with English as the default and conversation language chosen independently.
- Local conversation histories and HTML, JSON, Markdown and PDF exports.
- Encrypted credential storage, connection diagnostics and account switching after disconnecting.
- English and Spanish user manuals.
