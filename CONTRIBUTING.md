# Contributing

Use R >= 4.2.0. The repository root is the R package. From the root:

```r
install.packages(c("remotes", "testthat", "pkgload"))
remotes::install_deps(".", dependencies = TRUE, upgrade = "never")
testthat::test_local(".")
```

Build and check the exact artifact from the parent directory or with an explicit output directory. `tools/release.ps1 -AsCran` performs local Windows verification with `R CMD check --as-cran`, including PDF/HTML help, into `.local/` and puts the final archive in `dist/`; it does not publish or install into the normal user library. Supply explicit `-RBin` and `-Rscript` paths if R is not on PATH. TeX and Pandoc must be available for the complete check. The script refuses to overwrite a final archive or an existing stage. Preserve the previous candidate and its evidence in an ignored archive before a deliberate rebuild.

PDF manuals are generated by `tools/manual/build_manuals.py`; dependencies are in `tools/manual/requirements.txt` and editable sources in `docs/manual/`. Verify their R examples with `Rscript tools/manual/verify_examples.R`, and PDF bounds/text with `python tools/manual/verify_manuals.py`. Render with Poppler for visual inspection after changing layout or content. `tools/qa/verify-recovery.cjs` requires Playwright and Chrome, Rscript plus package test dependencies. `PLAYWRIGHT_MODULE`, `CHROME_PATH` and `RSCRIPT` can select local runtimes; run `node tools/qa/verify-recovery.cjs` from a clean output state. Its boundaries use synthetic data and do not authenticate.

Use two spaces, `<-`, snake_case and explicit namespaces. Keep R sources ASCII, using Unicode escapes for interface text; documentation and browser assets may use UTF-8. Add behavioral regressions for permission changes, malformed responses, cancellation and editor conflicts. Preserve native OAuth, loopback-only servers, restricted native IPC and explicit target authorization. Never execute model proposals without explicit user authorization.

CI is configured for Windows, Linux and macOS, including R development and previous-release configurations. It checks the package with synthetic dependencies at API boundaries; it does not run RStudio or authenticate with a real account. CI fails on errors and warnings. Keep native RStudio evidence separate and record the exact tarball/check-log hashes; a configured workflow is not a completed remote run. Current CRAN preparation is recorded in `docs/validation/cran-readiness.md`.

Use synthetic examples when reporting issues. Do not attach tokens, private histories or participant datasets. Publication, commits and pushes require the project owner's authorization.

Before publication, inspect `git status --short --untracked-files=all` and the actual files proposed for the commit. `dist/` and `.local/` are local output; manuals and sanitized evidence in `docs/` belong in the repository. Preserve approved historical designs as references, distinguishing them from the current implementation. Do not use `git add -f` to include credentials, private data or excluded artifacts.

The package author is José Gamarra-Moncayo, as stated in `DESCRIPTION`. Check `git var GIT_AUTHOR_IDENT` and `git var GIT_COMMITTER_IDENT` before the first commit; both must identify the responsible person. Do not add AI agents as authors, coauthors or signers, or insert automatic attribution trailers. Technical references to ChatGPT, OpenAI or Codex describe the integration and do not establish authorship. Preserve third-party license notices.
